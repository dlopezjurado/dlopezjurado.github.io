Abrir en Viajes

La aplicación te pedirá nombre, teléfono y aceptación. Esta página no pide esos datos ni recibe tu ubicación.

Si no se abre la aplicación
  1. Comprueba que tienes instalada la APK privada de Viajes.
  2. Abre este enlace en el navegador habitual del teléfono y pulsa de nuevo Abrir en Viajes.
  3. Como alternativa, abre Viajes → Grupo → Escanear QR o introduce el código de seis cifras del organizador.
  4. Si la invitación caducó, pide una nueva. No hace falta crear una cuenta en GitHub ni Supabase.

En iPhone este piloto Android no se puede instalar. La distribución de iPhone se estudiará en una fase posterior.

El QR es una puerta al viaje, no el seguimiento. La invitación es temporal y quien la recibe puede reenviarla. No la publiques fuera de tu grupo.

Para reducir exposición, la página retira los datos de invitación de la barra de direcciones después de leerlos. Si recargas, abre de nuevo el enlace original.
